 **🎓 AI Course Finder Agent**

An AI-powered course recommendation application built using Python, Streamlit, and the OpenRouter API.

**Features**

- Search by domain, including AI, Machine Learning, Data Science, Python, SQL, and Power BI.
- Get five course recommendations.
- Access official course links.
- Interactive Streamlit dashboard.
- Error handling and fallback recommendations.
 
** Technologies Used**

- Python
- Streamlit
- OpenRouter API
- Requests
- Visual Studio Code

**How to Run**

Install the dependencies:


pip install -r requirements.txt


Configure your OpenRouter API key using Streamlit secrets or an environment variable.

**Run the application:**


python -m streamlit run app.py


## Security

Never upload your actual API key or `secrets.toml` file to GitHub.
